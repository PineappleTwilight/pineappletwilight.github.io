Hyoukan is a free, open-source manga and novel reader for Android. It reads image chapters through a hardware-accelerated WebGPU renderer, opens EPUB books as real books, organises a library of thousands, and can translate and upscale pages entirely on your device — with no account and no content hosted by the app.

#What Hyoukan is

Hyoukan is a reader, not a catalogue. It does not host, index or distribute manga, novels or images. It displays content fetched by extensions — small APK packages installed separately, exactly as in Tachiyomi, Mihon and Komikku — or content you already own: local folders, CBZ/CBR archives, EPUB files and a self-hosted Komga server.

The app is a fork with a long lineage:

Tachiyomi
  ├── Mihon ──────────┐
  └── TachiyomiSY ────┴── Komikku ── Houri ── Hyoukan

Hyoukan keeps the entire Mihon and TachiyomiSY feature set, carries Komikku's additions, and adds its own work across the reader, the library, translation, upscaling, books, tracking, backup and diagnostics. It is licensed under Apache-2.0; the source lives at PineappleTwilight/hyoukan.

Note

A note on names. The project was previously published as Houri and before that as Komikku. The repository and update channels now use the Hyoukan name. The Android application ID is still app.houri so existing installs, backups and library databases continue to resolve; that identifier is an implementation detail, not the product name.

#What sets it apart

#A reader that takes rendering seriously

The WebGPU reader is the default on supported devices: HDR pages at full brightness, LUT colour grading, ArtCNN upscaling, dual-page spreads and a memory budget that follows the device rather than a fixed RAM class. When a GPU device genuinely cannot run it, the app falls back to the standard viewer and remembers why.

#Books are first-class, not image strips

Drop an .epub into a library folder and it opens as a book: the publisher's typography survives, illustrations and fonts travel inside the page, chapters flow continuously or turn as pages, positions survive font changes, and highlights, footnotes and text-to-speech are built in.

#AI that can stay on the device

Translation runs through a hybrid pipeline — on-device detection, OCR and inpainting, then a cloud LLM, Gemini Nano or a bundled llama.cpp model. Upscaling is a separate pipeline with Real-CUGAN, Real-ESRGAN, Waifu2x and imported ONNX models, and it works even in builds without the translation engine.

#A library that stays organised

Hierarchical categories, a home-screen-style folder layout, smart categories bound to tracker status, per-category reader settings and update schedules, duplicate detection, merging, migration and a feed that watches sources for you.
